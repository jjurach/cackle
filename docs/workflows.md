# Project Workflows - Cackle

This document describes development workflows for Cackle.

## Core Agent Workflow

All AI agents working on this project must follow the core A-E workflow defined in [AGENTS.md](../AGENTS.md):

- **A: Analyze** - Understand the request and declare intent
- **B: Spec** - Create specification for the work
- **C: Plan** - Create implementation plan
- **D: Approval** - Get explicit approval before proceeding
- **E: Implement** - Execute the approved plan

For complete workflow documentation, see the [Agent Kernel Workflows](system-prompts/workflows/).

## Project-Specific Workflows

Project-specific development workflows will be defined as the project develops.

**Note:** Cackle is in early-stage development. Detailed project workflows and processes will be established during the planning phase.
